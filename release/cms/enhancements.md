Public column grants and RLS expose payload only if referenced by a published snapshot; no private metadata or direct writes. Previously fetched images cannot be recalled. Unused images can be removed; referenced images cannot. Media previews use safe raster data URLs. No public uploads, SVG, external image URLs or raw HTML. Basic formatting toolbar + live preview, not arbitrary rich HTML. Featured event and two already public sponsors imported from exact existing static content, sponsor directory sorted, original recognition preserved; event overview and hero managed, other event details/SEO remain static. Original static cards retained as outage fallback (may show original content during API outage; unpublish not a permanent removal from fallback). New sponsors choose general, directory or featured recognition. No other sponsor records or amounts imported. No Gmail changes. CI verifies fixture-based access and publishing, actual device upload and preview need smoke test. No paid features, no new services.

Release order: run enhancement schema, import existing records only if no collision, merge web changes immediately after preflight, then test live. Prior published news remains intact.
